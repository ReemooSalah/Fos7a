# فُسحة للأطفال — Fos7a Kids

تطبيق تعليمي صوتي شامل للأطفال (3–12 سنة) باللغة العربية، مبني بـ Next.js 14 + Tailwind.

## المزايا

| القسم | التفاصيل |
|---|---|
| 🔤 الحروف | 28 حرفاً من الألف إلى الياء: أشكال الحرف (منفرد/أول/وسط/آخر)، الحركات، كلمات بالصور، نطق صوتي، **كتابة الحرف بالإصبع** على لوحة تتبّع، واختبار قصير |
| 🌟 قصص الأنبياء | 16 قصة بالترتيب الزمني من آدم إلى محمد ﷺ بنصوص كاملة مبسّطة |
| 🗣️ الصوت | قراءة آلية (Web Speech API) مع **اختيار صوت مختلف** وسرعة وطبقة من الإعدادات أو من المشغّل، أو ملفات صوتية مرفوعة |
| 🎮 الألعاب | ترتيب الحروف، كوّن الكلمة، اكتب الحرف، أي حرف تسمع؟، بطاقات الذاكرة، عدّ واختر |
| 👑 الاشتراك | 3 خطط، تفعيل **بالبريد الإلكتروني** مع رمز تحقق، تجربة 7 أيام، قفل المحتوى المميز |
| 🎛️ لوحة التحكم | `/admin` (الرمز 4444): إضافة/تعديل/حذف المحتوى، رفع ملف صوتي أو رابط، نص القصة، أصوات لكل حرف، تصدير/استيراد JSON |
| 👨‍👩‍👧 الوالدين | دقائق الاستماع اليومية، تقدّم الحروف، التفضيلات، آخر ما استمع إليه |
| ⭐ المكافآت | نجوم، 5 مستويات، 8 شارات، تحديات يومية |

## التشغيل

```bash
cd kids
npm install
npm run dev
# http://localhost:3000
```

## ملاحظات تقنية

- كل البيانات محفوظة في `localStorage` (لا يوجد خادم بعد). الملفات الصوتية المرفوعة تُحفظ كـ Data URL (حد 4MB للقصة و1MB للحرف)، وللملفات الأكبر استخدم رابطاً خارجياً.
- رمز التحقق بالبريد يُعرض على الشاشة في وضع التجربة. لربط إرسال حقيقي أضف API route يستخدم خدمة بريد (Resend / SendGrid) ويستبدل التوليد المحلي في `app/subscription/page.tsx`.
- القراءة الآلية تعتمد على أصوات النظام؛ على iOS فعّل الأصوات العربية من إعدادات تسهيلات الاستخدام.
